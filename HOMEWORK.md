# Домашнее задание lab07

Лабораторная работа Лисейчиковой Екатерины

## Что требовалось сделать

Домашнее задание относится к теме лабораторной работы VII: изучение систем управления пакетами на примере hunter.

## Выполненные пункты

- структура Hunter вынесена в `cmake/Hunter/config.cmake`; 
- для современных CI тесты продолжают подключаться через `FetchContent`, что не требует submodule и проще воспроизводится;
- demo-приложение показывает практическое использование formatter в утилите командной строки;
- переменная окружения `LOG_PATH` делает путь к логам переносимым.

## Как проверить домашнее задание

```bash
cmake -S . -B _build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
cmake --build _build
LOG_PATH=logs/log.txt ./_build/demo
ctest --test-dir _build --output-on-failure
```

## Пояснение по реализации

Проект оформлен так, чтобы его можно было перенести в Linux-окружение и собрать стандартными командами CMake. Файлы не завязаны на абсолютные пути macOS, персональные секреты не добавлены в git, а дополнительные инструменты подключаются через конфигурационные файлы конкретной лабораторной.
