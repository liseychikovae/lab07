# lab07

Лабораторная работа Лисейчиковой Екатерины

## Отчет по лабораторной работе VII

### Тема

Изучение систем управления пакетами на примере Hunter.

### Цель работы

Цель работы - оформить подключение внешних зависимостей и добавить demo-приложение logger.

### Используемое окружение

- основной целевой сценарий: Linux;
- язык: C++11;
- система сборки: CMake;
- дополнительные инструменты добавляются по теме конкретной лабораторной;
- персональные токены и временные адреса не сохраняются в репозитории.

### Структура проекта

- `formatter_lib` - базовая статическая библиотека форматирования;
- `formatter_ex_lib` - расширенная библиотека, использующая `formatter`;
- `solver_lib` - библиотека для решения квадратного уравнения;
- `hello_world_application` - демонстрационное приложение;
- `solver_application` - приложение для вывода корней уравнения;
- `tests` - модульные тесты, начиная с lab05;
- `docs` и `scripts` - дополнительные материалы поздних лабораторных.

### Ход выполнения

- создан каталог `cmake` для файлов управления зависимостями;
- добавлен `cmake/Hunter/config.cmake` с версией GTest;
- оставлен легкий `HunterGate.cmake`-placeholder для отчета и структуры лабораторной;
- добавлено приложение `demo`, читающее строки из stdin и пишущее лог по `LOG_PATH`; 
- demo устанавливается в `bin` и используется в следующих лабораторных.

### Команды для проверки

```bash
cmake -S . -B _build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
cmake --build _build
LOG_PATH=logs/log.txt ./_build/demo
ctest --test-dir _build --output-on-failure
```

### Домашнее задание

Домашнее задание выполнено внутри этого же репозитория. Подробное описание вынесено в `HOMEWORK.md`.

Кратко по выполнению:

- структура Hunter вынесена в `cmake/Hunter/config.cmake`; 
- для современных CI тесты продолжают подключаться через `FetchContent`, что не требует submodule и проще воспроизводится;
- demo-приложение показывает практическое использование formatter в утилите командной строки;
- переменная окружения `LOG_PATH` делает путь к логам переносимым.

### Результат

Репозиторий подготовлен к управлению зависимостями и содержит консольное demo-приложение для дальнейшего Docker-развертывания.
